# EXTERNAL_LINKS_CHECK — 외부 링크 브라우저 확인 (RELEASE-CHECK-EXTERNAL-LINKS)

- **Requirement:** REQ-FUNC-016, REQ-FUNC-024, REQ-FUNC-049
- **Scope:** SCR-001(`/`), SCR-003(`/travel-tools`)

## 이 문서의 성격

배포 직전 사람이 실제 브라우저에서 확인하는 릴리스 게이트 Task다. Claude Code가
자동화로 대체할 수 없다(설계상 사람의 눈으로 실제로 새 탭이 열리고 목적지가
맞는지 확인해야 한다). 아래는 확인해야 할 링크의 정확한 위치와 확인 방법을
정리한 것이다.

**중요(사람 확인 후 해결됨)**: 이 체크리스트를 준비하는 중, 홈 화면의 여행지/
안전정보 Card를 클릭해도 상세 Drawer가 전혀 열리지 않아 외교부 안전정보 링크
자체에 도달할 수 없는 버그를 발견했다. 사람에게 확인받은 뒤 `PAGE-SCR001`을
수정해 해결했다(`TASK-PAGE-SCR001.md` 참고) — 지금은 아래 경로로 실제 확인할 수
있다.

## 확인 방법

### 1. 항공편 외부 이동 링크(REQ-FUNC-016)

1. `/travel-tools`로 이동한다.
2. "항공편" 탭을 선택한다.
3. 국가·지역·출발일·귀국일을 입력하고 "계속"을 누른다.
4. 요약 화면에서 "항공편 보러 가기" 버튼을 클릭한다.
   - 외부 URL이 설정되어 있지 않으면(로컬/Preview 환경에 따라 다름) "설정되지
     않았습니다" 오류 카드가 대신 뜬다 — 이 경우 이 항목은 "환경 미설정으로
     확인 불가"로 기록하고 넘어간다.

- [ ] 새 탭(현재 탭이 유지된 채)으로 열렸다.
- [ ] 열린 탭의 주소가 실제 항공 검색 사이트로 보인다(HTTPS).
- [ ] 주소창 URL에 입력했던 국가·지역·날짜 등 값이 쿼리 파라미터로 보이지
      않는다(REQ-FUNC-016 — 입력값 비전달).

### 2. 숙소 외부 이동 링크(REQ-FUNC-016)

같은 화면에서 "숙소" 탭으로 위 과정을 반복한다.

- [ ] 새 탭으로 열렸다.
- [ ] 열린 탭의 주소가 실제 숙소 검색 사이트로 보인다(HTTPS).
- [ ] 입력값이 쿼리 파라미터로 붙지 않는다.

### 3. 외교부 해외안전여행 링크(REQ-FUNC-049)

1. 홈(`/`)으로 이동한다.
2. "국가별 주의사항" Section에서 해외 국가 Card를 하나 클릭한다(예: 일본).
3. 안전정보 Drawer가 왼쪽에서 열리는지 확인한다.
4. Drawer 안의 "대한민국 외교부 해외안전여행(0404) 원문 보기(새 탭)" 링크를
   클릭한다.

- [ ] Drawer가 실제로 열렸다(카드 클릭 반응 확인).
- [ ] 링크가 새 탭으로 열렸다.
- [ ] 열린 탭이 실제 외교부 해외안전여행(0404.go.kr) 페이지로 보인다.

### 4. (참고) 여행지 상세 Drawer 자체도 함께 확인

3번 과정 전에 해외/국내 여행지 Card를 클릭해 `DestinationDrawer`가 열리는지도
함께 확인해 두면 좋다(REQ-FUNC-004/009, 이 Task의 직접 범위는 아니지만 같은
버그로 함께 막혀 있었다).

- [ ] 여행지 Card 클릭 시 상세 Drawer가 열린다.
- [ ] 해외 여행지 상세에서 "안전정보 보기" 버튼을 누르면 안전정보 Drawer로
      전환된다.
